# Change log

What changed in Payrudder, release by release. It is made when this site is built, from the history of the repository: the releases are the tags `vX.Y.Z`, and each entry is the title of a pull request that was merged. Nothing is written by hand and nothing is added that was not merged.

**There is no release yet.** The owner's rule is that nothing is tagged or published until the application is complete, so there is no version to list; the platform, the SDKs and the command line all say `0.0.0`. Until the first release the page shows the latest pull requests under "Unreleased". The SDKs keep their own change logs (`sdk/<language>/CHANGELOG.md`) and are tagged separately (`sdk/go/vX.Y.Z` for the Go module).
