Other changes of this pass (all with tests):

- **`custom_data` keys** written as `payrudder_subscription_id`, `payrudder_migration_id`, `payrudder_plan_code`, `payrudder_customer_id` (were `quotify_*`); the two keys the adapter reads back (`*_subscription_id`, `*_migration_id`) are read in both spellings, the new one first, because Paddle returns the old spelling for objects created before the rename (ADR 0022).
- **Pagination**: `listAll` follows `meta.pagination.has_more` and the `after` value of `next`, never the `next` URL itself (the key is only sent to the configured host), sends `Skip-Count: true`, `per_page=200` for addresses and businesses, and stops at 50 pages [`TestListsFollowThePaginationCursor`, `TestListStopsOnAPageThatHasMoreWithoutACursor`]. Pagination page: `api-reference/about/pagination.md`, read 2026-11-02.
- **`Retry-After`** is surfaced as `payments.TransientError.RetryAfter` and read by payments-worker's delay queues (F4).
- **Partial refund**: before, any amount refunded the whole transaction (`type: "full"` always). Now: no amount or the transaction's `grand_total` = full; a smaller amount on a transaction with one line item = a `partial` adjustment of that item (`items[{item_id txnitm_..., type partial, amount}]`, amounts inclusive of tax by default, per create-adjustment); several line items, an amount above the total or another currency = refused without creating an adjustment [`TestRefundAmounts`, conformance `partial refund`]. Default (not agreed): refuse rather than split an amount across items.
- **Preview credit sign**: the documented preview example has `credit.amount` "-4927" next to a `charge` of "83765" and a `result` of "78838"; `ChangePreview.CreditMinor` is now the credit's size [`TestPreviewReportsACreditAsItsSize`].
- **`Content-Type`** is sent only with a body (as Paddle's Go SDK does).
- The skipped sandbox test (`TestSandbox`, health check and a paged list) did not exist although the package comment said it did; it exists now and has never run.

Conformance: `TestConformance` in this package runs `pkg/payments/conformance` against a fake of Paddle's API (`docs/payment-provider-contract.md`).
