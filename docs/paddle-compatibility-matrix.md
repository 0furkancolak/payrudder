# Paddle Billing adapter: compatibility matrix

Read on 2026-10-29. Adapter: `pkg/payments/paddle/{paddle.go,api.go,invoice.go}` (paths below are relative to that dir). Wired by `services/payments-worker/cmd/payments-worker/main.go:170` (`paddle.Register`); webhook route `services/payments-worker/internal/webhook/webhook.go:174`.

Method note: docs pages were fetched through WebFetch, which returns a model-written summary of the page, not the raw page. Where a page was truncated (create-transaction, update-subscription, preview-subscription-update, get-subscription-update-payment-method-transaction, the three webhook event pages) only the first ~100k chars were read; anything not in that part is UNVERIFIED. Docs base: https://developer.paddle.com. All `.md` URLs are the Markdown twins of the HTML pages.

Status legend: current / deprecated / removed / changed / UNCLEAR (docs do not settle it) / UNVERIFIED (could not fetch).
