## Patterns

- **Merged on own tests, CI unread.** 22 of 22 heads had a red `operator console` job, 19 a red `end-to-end (compose)`; only #247, #249, #250 say which failures were already on main. Rule: working agreement 3 (`docs/plans/README.md`), `make ci-local`.
- **The merge's own `ci` is cancelled by the next merge** (`cancel-in-progress: true`, `ci.yml:11-13`). Latest 60 `ci` runs on main, read today: 49 cancelled, 8 failed (#275, #278, #279, #289, #293, #304, #315, #320), 2 passed (#264, #273; last 2026-10-29). "Read CI after merge" fails for most merges. **Open, in no plan:** read the PR's checks before merging, or stop cancelling on main.
- **Generated code edited by hand.** php red on 8 heads; 5 edited `sdk/php` by hand (#236, #240, #242, #252, #253). Rule: Definition of done 2-3, `make gen` plus clean `git diff` in `ci-local`, which still lacks the Go, Python, TS SDK, docs-site and mcp checks (plan 01 addendum).
- **Error key not listed** (#242). Rule: Definition of done 4 (`go test ./pkg/errkey`).
- **Assumed outside contracts, code never run.** Nafru, Stripe, snippets, labelled accounts on the database, the price-change mail. Rule: working agreement 5 (UNVERIFIED), conformance suite (#285), fake Nafru (#292), compiled snippets (#288), integration tests through the real database and broker.
- **One path guarded, not all** (block, suspend). Rule: `pkg/paymentgate` (#282), path-by-gate matrix (Definition of done 9).
- **Contract built per page, then completed** (filters, sort, bulk: 2 to 8 lists, finished in #261, #280, #324). Rule: "Lists" in `docs/13-admin-ui.md`, data-driven `list-contract.spec.ts`.
- **Docs lag.** Only #236, #244, #245, #252, #253, #254 changed a document besides the roadmap. Every PR that touched a locale touched all six (wording not judged). Rule: Definition of done.
